# Archivo Histórico de Balotarios MTC

Este directorio tiene como objetivo salvaguardar la trazabilidad normativa y auditoría cívica de los balotarios oficiales del Ministerio de Transportes y Comunicaciones (MTC).

## Política de Versionado Histórico
1. Cuando el MTC promulgue un nuevo Decreto Supremo o Resolución Directoral que modifique el banco de preguntas, los archivos PDF vigentes se trasladarán a una subcarpeta fechada (ej. `2024-historico/`, `2025-historico/`).
2. La nueva versión entrará directamente a la carpeta principal `2026-vigente/`.
3. Esto garantiza que conductores, abogados de tránsito e investigadores puedan consultar la evolución de las infracciones y normativas viales a lo largo de los años.
